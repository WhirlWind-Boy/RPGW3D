# Asset Files (Optional)

The game works without these files - it will generate procedural graphics as fallbacks. However, if you want custom graphics, add these image files to the root directory:

## Textures
- `Brick_Wall_64x64.png` - Wall texture
- `Dirt_Road_64x64.png` - Floor texture
- `Grass_Ground_64x64.png` - Grass floor

## Sprites
- `DeadTree.png` - Dead tree sprite
- `LeafyTree.png` - Leafy tree sprite
- `bush.png` - Bush sprite
- `rocks.png` - Rock sprite
- `fireball.png` - Fireball projectile
- `clouds_pixel.png` - Cloud parallax sprite

## UI Icons
- `Key_Icon.png` - Key item icon
- `Sword_Icon.png` - Sword icon
- `food.png` - Food item icon
- `artifact.png` - Artifact icon
- `health_potion.png` - Health potion icon
- `mana_potion.png` - Mana potion icon

## Audio (Optional)
- `bgm.mp3` - Background music
- `dungeon_rainstorm.mp3` - Dungeon music
- `pickup.wav` - Pickup sound
- `door.wav` - Door sound
- `error.wav` - Error sound
- `use.wav` - Item use sound
- `walking.mp3` - Footstep sound
- `raining.mp3` - Rain ambient sound
- `shoot_fireball.wav` - Fireball cast sound

## Data Files (Optional)
- `map_data.json` - Custom map layout
